# Vídeos, clases y entrevistas de YouTube

Los vídeos son útiles para recuperar razonamientos, técnicas descritas y bibliografía mencionada. **Un vídeo no es, por sí mismo, evidencia científica del mecanismo afirmado.**

Guardar por defecto **fichas originales redactadas con nuestras palabras**, con título, autor, URL, fecha de consulta, minutos concretos, afirmaciones, bibliografía invocada y revisión crítica.

No incorporar automáticamente transcripciones completas de terceros aunque el repo sea privado: el contenido puede estar protegido. Solo incluir transcripción íntegra cuando sea propia, haya licencia compatible o autorización explícita/otra excepción aplicable, con prueba documental. La licencia estándar de YouTube no autoriza redistribución libre; respetar sus condiciones y las leyes aplicables.

Para cada vídeo: duplicar [PLANTILLA.md](PLANTILLA.md), aportar enlace y verificar los estudios citados antes de añadir claims. No almacenar vídeos, audio ni subtítulos descargados sin permiso.
