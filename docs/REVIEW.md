# Revisión antes de incorporar o publicar afirmaciones

- [ ] Fuente primaria consultada (al menos abstract, preferentemente texto completo permitido).
- [ ] Metadatos DOI/PMID y diseño comprobados.
- [ ] Criterios diagnósticos e instrumentos diferenciados.
- [ ] Si se responde a una objeción: comprobado el ajuste entre hipótesis y variable medida; límites documentados separados de posibilidades; mismos estándares para evidencia favorable y contraria ([enfoque](ENFOQUE-CRITICO.md)).
- [ ] Evidencia contraria y explicación alternativa documentadas.
- [ ] No se infiere causalidad desde asociación o temporalidad de un caso.
- [ ] Revisión de términos sensibles: «demuestra», «produce», «corrige», «siempre».
- [ ] Licencia y derechos de autor revisados; no PDFs/transcripciones ajenas sin permiso.
- [ ] Datos de salud/menores/PII eliminados del historial completo de Git, no solo del HEAD.
- [ ] Discusión de riesgos de diagnósticos/tratamientos disponible cuando corresponda.
- [ ] Revisión científica humana de claims públicos.
